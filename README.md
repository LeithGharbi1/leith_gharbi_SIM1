# Student Management System

A student management backend developed with **Spring Boot** and **MySQL**, with a focus on containerization, CI/CD, code quality, and monitoring.

### What I did

- Developed a REST API using **Spring Boot, JPA and MySQL**
- Containerized the application using **Docker** and published the image to **Docker Hub**
- Deployed the application and database on **Kubernetes** using **Minikube**
- Built a **Jenkins CI/CD pipeline** to automate the build, Docker image creation, publishing, and deployment
- Integrated **SonarQube** for static code analysis and code quality checks
- Set up **Prometheus and Grafana** for application monitoring and metrics visualization

### Technologies

**Java · Spring Boot · MySQL · Docker · Docker Hub · Kubernetes · Minikube · Jenkins · SonarQube · Prometheus · Grafana · Maven**
